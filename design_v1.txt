0. Purpose & product intent
--------------------------------------------------------------------------------

Migrate the **live execution path** of the MQ4 / cBot strategy stack onto the
cTrader Open API (Python + Twisted), not the full MQ4 surface area.

Primary references (read-only migration sources):
  code_references/mq4/code_base_v98.txt   — entry: HSIG::initSIG
      (identical copy: ../code_base/mq4_code_base_v98.txt)
  code_references/cBot/                   — PhyBot.cs, CSignal.cs, CStrategies.cs,
                                            CStats.cs, CTypes.cs, PhysicsEngine.cs
      (concatenated: ../code_base/cb_v1_v2.txt)

MQ4 live chain being ported (parity ground truth; MQ4 input activeStrategy=3):
  OnTick → OnCycleTask1 → RefreshPhysicsData → imaSt3 → SS::update
         → HSIG::initSIG → setSIGForStrategy_v3 → dominantSIG → OnEntryExit_3
  cBot is a partial, divergent port (SMA, slope 3/5, Strategy_2, pyramiding);
  where MQ4 and cBot disagree, MQ4 wins.

Principles:
  1. Match **behavior** of the live path over porting unused helpers.
  2. Once-per-bar indicators + signals; rest of the cycle only reads snapshots.
  3. Single market position per symbol; no pyramid; no SL/TP unless redesigned.
  4. Strict layer split: capp → csys; csys must never import capp.
  5. Extend by well-scoped tasks (this file), not drive-by refactors.

Out of scope (unless a task explicitly reopens them):
  - Full MQ4 SanStrategies / SanSignals surface
  - Pyramid trading (mq4 up to 15 trades, one per new candle)
  - main_fastapi.py / basic.py as production paths
  - Automatic reverse-and-open on the same bar after opposite signal

      [EXEC] OPEN/CLOSE … (when the strategy acts)

  Troubleshooting
    "❌ Open API error … / ❌ Auth failed before ready — stopping"
        → bad client id/secret, expired access token, or account/host mismatch.
          The client stops the reactor instead of retrying forever.
    "Missing required environment variable: …" → .env missing or incomplete.
    Far fewer than 2000 historical bars (e.g. Monday morning)
        → get_trendbars sizes its window as count×1.5 minutes (≈50 h for 2000
          M1 bars), which spans the weekend gap. Long MAs (ima500) then run
          on less warm-up (G16).
    No "New bar closed" lines → market closed (no spot events), or live
        trendbar subscribe failed (look for ❌ Live trendbar subscribe failed).
    Existing positions not managed → they were opened under another label
        (e.g. legacy "GrokApp"); only label cSanOpenAPI is reconciled (G21).
    Disconnect mid-session → no auto re-subscribe (G7); restart the process.

1.3 Types & constants (single source of truth)
----------------------------------------------

  Canonical: csys/ctrader_api/ctypes.py
  Import:    from csys.ctypes import SIG, IndData, DTYPE, T_SIG, SymbolMeta
             (or from csys import …)

  SIG: HOLD=101 BUY=102 SELL=103 CLOSE=104 TRADE=105 NOTRADE=106
       SIDEWAYS=107 NOSIG=108

  DTYPE: multi-value slope/kinematics transport (val1..val5)
  T_SIG: once-per-cycle tactical bundle (fsig5..fsig500, base_slope_data,
         slope30_data, base_slope_sig, slope30_sig, fast_sig, micro_wave_sig,
         strategy_sig, open_sig; camelCase property aliases baseSlopeSIG, …)
  IndData: OHLCV deques (oldest→newest) + indicator deques + trading state
           + symbol meta (pip_size, point, digits, pip_position, period,
           pip_value, dbl_epsilon) + placeholder physics/score fields
  SymbolMeta: from ProtoOASymbol (digits, pipPosition → pip_size=10^-pipPos,
              point=10^-digits, approximate pip_value, min/step volume)
  Helpers: decode_trendbar (low + deltas → OHLCV, utc_minutes),
           relative_to_price (÷100000), period_seconds("M1")=60,
           symbol_meta_from_proto, apply_symbol_meta

  Constants:
    PRICE_SCALE           = 100_000  (Open API relative price unit)
    DEFAULT_BAR_CAPACITY  = 500      (IndData() default; cindicators size cap)
    DEFAULT_HISTORY_BARS  = 2000     (live app: IndData capacity AND trendbar
                                      seed count — SMMA warm-up for ima240/500)

  Do **not** add a second types module under capp.

1.4 Series & indexing convention
--------------------------------

  IndData series: oldest → newest (Python deque; index -1 = newest).
  MQ4/cBot shift: 0 = newest. Bridge via capp.signals.stats.mql_at / mql_index.
  Live closed-bar analysis uses shift=1 (IndData.shift=1 set in init_ind_data):
  after a minute roll the last slot is the newly opened bar, so shift 1 is the
  bar that just closed — same as MQ4 close[1] / ima[1].

  Pitfall: cindicators._utils.finalize(values, size=None) caps output at
  DEFAULT_SERIES_CAPACITY=500. Internal callers must pass an explicit size
  (compute_indicators passes size=len(close)).

1.5 Per-bar pipeline (as implemented)
-------------------------------------

  Implemented in CTraderApp.run_signal_cycle():

    IndData (OHLCV)
      → compute_indicators(ind)                    # csys.cindicators.snapshot
      → [live only] fetch_position_pnls()          # single-flight reconcile
            → SanUtils.get_total_trade_profits()   # multi-asset avg float PnL
      → CStrategies.evaluate(ind, total_trade_profits)
            → SanSignals.init_sig(ind) → T_SIG
            → Strategy_N(t_sig[, pnl][, symbol_id]) → SIG
      → _sync_position_state
      → OrderExecutor.handle_signal(symbol_id, sig)   # only if execute & ready
      → _sync_position_state
      → _log_cycle_result ("New bar closed …")

  Gates:
    History seed:  execute=False  (indicators+signals only; no orders, no PnL)
                   NOTE: Strategy_6 sticky state IS updated by the seed cycle
                   (Strategy_7 / Strategy_8 are stateless).
    Live after _hist_ready: execute=True
    dry_run: PnL fetch returns [] (avg 0); executor simulates fills
    enabled=False on OrderExecutor: handle_signal → "skipped"

  Rule: indicators + signals once per bar; rest of cycle only reads IndData /
  T_SIG / last_trade_sig / last_total_trade_profits.

1.6 Startup & live lifecycle
----------------------------

  Detail diagram: ctraderapp_flow.txt

  main.py
    → argparse --dry-run ; load_config() (also loads .env into os.environ)
    → dry_run = --dry-run or CTRADER_DRY_RUN in {1,true,yes,on}
    → CTraderApp(config, active_strategy=8, dry_run=dry_run).run()
         (trade_volume=10000, trade_label="cSanOpenAPI", trading_enabled=True
          are CTraderApp defaults)
    → CTraderOpenAPI.run() → Client.startService → reactor.run()
    → TCP/TLS connect → ApplicationAuthReq → AccountAuthReq
         (handled inside client._on_message, not via Deferreds)
         ErrorRes before ready → log + reactor.stop (no infinite retry)
    → on_ready = CTraderApp.on_init
         → subscribe_spots(fxpair_arr, subscribe_to_timestamp=True)
         → get_symbols → symbol_map (id → name)
         → get_symbols_by_id(fxpair_arr) → SymbolMeta cache
              (on failure / missing id: FX5 defaults digits=5 pip=0.0001)
         → init_ind_data: IndData(capacity=2000) per symbol, apply meta,
              shift=1, get_trendbars(period=M1, count=2000)
         → on_historical_bars_received: decode, sort by utc_minutes, load_bars,
              run_signal_cycle(execute=False)  (seed)
         → when all symbols done (success or error): _hist_ready=True
              → executor.sync_positions (reconcile; skipped in dry_run)
              → mirror positions onto IndData.trade_position / total_orders
              → subscribe_live_trendbars(M1) per symbol
    → on_message forever:
         has executionType → OrderExecutor.on_execution_event
         else on_tick:
           * ignore unless is_spot_event(message) (ProtoOASpotEvent) — the SDK
             replays EVERY RPC response (GetTrendbarsRes, ReconcileRes, …) and
             events like SymbolChangedEvent (repeated symbolId) into
             on_message before the request Deferred fires
           * symbol_id = int(message.symbolId); ignore if not watched
           * trendbar[] present → _apply_live_trendbar:
               same minute → update_last_bar; minute rolled → append bar,
               run_signal_cycle(execute=True), fire on_bar handlers
           * else bid/ask → synthetic mid-price bar (fallback clock on
             bar_interval; run_signal_cycle tagged "synthetic")

1.7 Signal generation path (SanSignals.init_sig)
------------------------------------------------

  Parameters match MQ4 SS::update / HSIG::initSIG:
    base_slope_data = slope_val(ima240, 5, 21, shift=1, pip, point)
    slope30_data    = slope_val(ima30,  5, 21, shift=1, pip, point)
        val1 = round((x[s]-x[s+5]) /(5·pip), 4)
        val2 = round((x[s]-x[s+21])/(21·pip),4); val3=val4=val1-val2
        (constants SLOPE_DENOM=5, SLOPE_DENOM_WIDE=21 in signals.py;
         cBot's 3/5 is a divergence, not the reference)
    base_slope_sig  = kinetic_acceleration_sig(val1, val2, 0.015, -0.06)
    slope30_sig     = kinetic_acceleration_sig(val1, val2, 0.015, -0.2)
        |slow|<=zone → CLOSE; ratio=(fast-slow)/slow;
        ratio >= -0.05 → BUY/SELL by sign(fast); ratio < close_limit → CLOSE;
        else NOSIG; NaN → NOSIG
    base_slope_sig_v1 = _kin_v1(sid,"base",   …, close_acc=0.010 | close_limit=-0.20)
    slope30_sig_v1    = _kin_v1(sid,"slope30",…, close_acc=0.015 | close_limit=-0.30)
        (V1-T26/T27; not MQ4) atr_pips = ATR[s]/pip; trend=|slow|/atr_pips.
        Flat regime (kin_v1_flat_regime, real hysteresis): trend<0.01 → flat,
        trend>=0.02 → trending, between → previous regime, kept per
        (symbol_id, series) in SanSignals._kin_v1_flat (None → NOSIG band).
        NaN or atr<=0 → NOSIG; flat → SIDEWAYS.
        Trending, kin_v1_mode="acc" (default): acc = sign(s)·(f-s)/atr_pips;
          f·s>0 & acc >= +0.002 → BUY/SELL by sign(slow) (convex + margin);
          f·s<=0 or acc < -close_acc → CLOSE (reversal/decel); else NOSIG.
        kin_v1_mode="ratio" (V1-T26 baseline): ratio=f/s-1 >= 0 → BUY/SELL;
          < close_limit → CLOSE; else NOSIG.  Gates use 1e-9 tolerance.
        SanSignals(kin_v1_mode=…); CStrategies.reset_state also clears regime.
    base_slope_sig_v2 = kinetic_acceleration_sig_v2(kin_v2_data.val1,
        kin_v2_data.val2, atr_pips)   (V1-T32; not MQ4; stateless; Strategy_9)
        kin_v2_data = slope_val(ima{kin_v2_period}, 5, 21), period default 120
        (SanSignals(kin_v2_period=…), one of 5/14/30/60/120/240/500).
        old = (21·s - 5·f)/16 (slope of bars 5..21, tail removed);
        f, o = f/atr_pips, old/atr_pips.  NaN / atr<=0 → NOSIG.
          |f| < 0.01 → SIDEWAYS if |o| < 0.02 else CLOSE (stalled after move)
          |f| < 0.02 → NOSIG (dead band, no new entry)
          accel = sign(f)·(f - o) >= +0.01 → BUY/SELL by sign(f)
          accel <= -0.03 → CLOSE (decel); else NOSIG (steady trend, hold)
    slope_dist_sig = slope_distribution_sig(slope_dist_data)   (V1-T34; not
        MQ4; stateless; computed every bar, read by no strategy yet)
        slope_dist_data = slope_distribution(close, 60, shift): 59 one-bar
        slopes (pips/bar) → val1 Kelly skew (P90+P10-2·P50)/(P90-P10),
        val2 upper tail (P90-P50)/(P75-P50), val3 lower tail
        (P50-P10)/(P50-P25) (normal ≈ 1.90), val4 median, val5 count.
          NaN shape (flat / short) → NOSIG
          min(val2, val3) > 2.6 → NOTRADE (heavy tails both sides: whipsaw)
          Kelly <= -0.25 & median > 0 → BUY; Kelly >= +0.25 & median < 0 → SELL
          else NOSIG (symmetric, or skew vs. median conflict)
    peak_trough_sig = peak_trough_sig(high, low, zone=0.5·atr_pips,
        close=close[shift])  (V1-T29, reworked V1-T31; not MQ4; stateless;
        read by Strategy_8)
        find_extrema(order=5) on raw prices of the last 240 closed bars
        (shift excludes the forming bar); peaks on high, troughs on low.
        Each side: last two extrema, |diff| <= zone → 0, else ±1.
        Break override: close > last peak + zone → peaks = +1;
        close < last trough - zone → troughs = -1.
        pt_mode="structure" (default): score = peaks + troughs;
          > 0 → BUY, < 0 → SELL, 0 → SIDEWAYS; < 2 peaks or troughs → NOSIG.
                     troughs:  higher    flat      lower
          peaks higher         BUY       BUY       SIDEWAYS
          peaks flat           BUY       SIDEWAYS  SELL
          peaks lower          SIDEWAYS  SELL      SELL
        pt_mode="peaks" (V1-T29 baseline): peaks only, +1 BUY / -1 SELL /
          0 SIDEWAYS. ATR NaN/<=0 → NOSIG.
    fsig{5,14,30,60,120,240,500} = fast_slow_sig(close[1], ima*[1])
        sign of PPO only (threshold_pct kept for API parity, unused)
    fast_sig = fuse(fuse(fsig5, fsig14), fsig30), or CLOSE if NOSIG
        fuse: BUY=+1 SELL=-1; |Σ|>0.5 → dir; |Σ|<0.1 → HOLD; else CLOSE
    micro_wave_sig = interim proxy (fsig30 == base_slope_sig directional →
                     that side; base CLOSE → CLOSE; else NOSIG). Real
                     MQ4 microWaveSIG not ported (G1) — Strategy_1 only.

  Pure helpers also available: compute_stencil_kinematics (MQ4 index
  convention; not consumed by any strategy — G2).

1.8 Strategies (CStrategies)
----------------------------

  CStrategies(signals, active=N, profit_close_threshold=4.0,
              mq4_profit_close_threshold=2.0). main.py uses active=6.
  evaluate(ind, total_trade_profits) → init_sig → run_strategy(N) → SIG;
  also prints " Total Trade Profits: … Active Strategy: …" every cycle.
  Unknown N falls back to Strategy_1.

  Strategy_1  micWave alignment: fsig5==fsig30==micro_wave_sig directional
              else CLOSE
  Strategy_2  cBot Strategy_2: base!=CLOSE & fast==HOLD → CLOSE;
              base==CLOSE & pnl>=4.0 → CLOSE; entry needs fsig5==fsig30==
              fast_sig==base directional; else NOSIG
  Strategy_3  as 2 but first branch is base==CLOSE & fast==HOLD
  Strategy_4  slope30: CLOSE&HOLD → CLOSE; CLOSE&pnl>=4.0 → CLOSE;
              directional slope30 → that side
  Strategy_5  slope30 CLOSE → CLOSE; pnl>=4.0 → CLOSE; directional slope30
              → that side; else NOSIG  (Python-only; no MQ4/cBot origin)
  Strategy_6  MQ4-parity baseline (live default until V1-T26) — MQ4 HSIG::initSIG "baseSlopeSIG Strategy"
              → setSIGForStrategy_v3 → SanStrategies::dominantSIG:
                base!=CLOSE & fast==HOLD        → composite close
                base==CLOSE & pnl >= 2.0        → composite close
                base BUY/SELL                   → composite open = base
                                                  (no fsig alignment gate)
                otherwise                       → composite unchanged
              v3: close wins, else directional open, else unchanged.
              dominant: SIDEWAYS > CLOSE > directional open > NOSIG.
              Sticky per-symbol state in _HSigState (composite_open,
              composite_close, open_sig, close_sig) mirrors the MQ4 HSIG
              object living for the EA lifetime; reset_state([symbol_id])
              is MQ4 baseInit().
              Deviations (documented in docstring): evaluated once per closed
              bar (MQ4 per tick); pnl = multi-asset label average (TASK 7);
              single position, no pyramid (TASK 2).
  Strategy_7  (V1-T26, intentional MQ4 deviation; live default until V1-T30) — clean
              baseSlope on base_slope_sig_v1, stateless (the flat
              regime state lives in SanSignals, V1-T27):
                v1 SIDEWAYS (flat)               → CLOSE (always)
                v1 CLOSE (decel) & pnl >= 2.0    → CLOSE
                v1 CLOSE (decel) & pnl <  2.0    → NOSIG (hold)
                v1 BUY/SELL                      → that side
                otherwise                        → NOSIG
              Drops Strategy_6's fast==HOLD close branch. Threshold:
              CStrategies(decel_profit_close_threshold=2.0).
  Strategy_8  **LIVE DEFAULT** (V1-T30, not MQ4) — market structure on
              peak_trough_sig (pt_mode="structure" since V1-T31),
              stateless, no PnL gate:
                pt SIDEWAYS (flat / conflicting structure) → CLOSE (always)
                pt BUY / SELL (peaks + troughs score)      → that side
                otherwise                                  → NOSIG (hold)
              Opposite side closes via the executor; re-entry next bar.
  Strategy_9  (V1-T32, not MQ4) — kinetic v2 on base_slope_sig_v2,
              stateless, no PnL gate (quick exit):
                v2 SIDEWAYS or CLOSE → CLOSE (always)
                v2 BUY / SELL        → that side
                otherwise            → NOSIG (hold)
              Select with CTraderApp(active_strategy=9); not the live default.

1.9 Execution policy (OrderExecutor, TASK 2)
--------------------------------------------

  Condition                    Action
  ---------------------------  ---------------------------------------------
  BUY/SELL while flat          Open one market order (comment "TASK2 single-trade")
  BUY/SELL same side           No-op
  HOLD/NOSIG/SIDEWAYS in pos   No-op (hold)
  Opposite signal              Close only (no reverse open same cycle)
  CLOSE                        Close open position
  CLOSE with position_id 0     Reconcile first (optimistic open state), then close
  Order already pending        Skipped
  SL / TP                      Never attached
  Pyramid                      Forbidden (max 1 position per symbol)
  Label                        "cSanOpenAPI" (CTraderApp default; OrderExecutor's
                               own default "GrokApp" is overridden). Reconcile
                               and PnL only see positions with this label.
  dry_run / enabled            Simulated fills / master off

  Volume: high-level units (10000 ≈ 0.1 lot FX); protocol volume = ×100.
  Execution events update the book (filled/partial → open, CLOSED → remove).

  Defaults (code): fxpair_arr=[1,4] (broker-dependent IDs), period M1,
  capacity/history 2000 bars, volume 10000 units, strategy 8.

1.10 Account PnL path (TASK 7–11)
---------------------------------

  Network (CTraderApp only — not SanUtils):
    fetch_position_pnls (single-flight; dry_run → []):
      1. api.reconcile(timeout=30, client_msg_id=pnl_reconcile_<seq>)
      2. executor.sync_from_reconcile
      3. api.get_unrealized_pnl(timeout=30, pnl_unrealized_<seq>)
         netUnrealizedPnL scaled by moneyDigits (scale_money)
      4. merge → list[PositionPnL] (open, label-matching)

  Pure average (capp.utils.SanUtils):
    get_total_trade_profits(positions, label=…)
      = sum(net_profit of open matching label) / count
    Multi-asset by default (all symbols under label).
    Magic number optional (mq4 legacy only).
    Deviation: MQ4 divides by unfiltered OrdersTotal(); we divide by the
    filtered count (TASK 7 spec).

  Concurrent multi-symbol bars join one in-flight fetch (_share_pnl_result
  fans out to per-caller Deferreds). Failures degrade to avg=0 and still run
  strategy/execution.

1.11 Open API client surface used by the app

  Module helpers: is_spot_event(msg), scale_money(value, money_digits)

1.12 Indicators computed (compute_indicators, MQ4 RefreshPhysicsData parity)
----------------------------------------------------------------------------

  Series                 Method                               Period
  ---------------------  -----------------------------------  -------------
  ima5/14/30/60/120/     SMMA on close (MQ4 MODE_SMMA;         as named
    240/500              SMA-seeded, Wilder recursion)
  atr                    simple mean of TR (MQL4 iATR)         21
  adx, adx_plus/minus    Wilder ADX / DI (not MT4 EMA iADX;    21
                         diagnostic only on live path)
  std_close, std_open    iStdDev MODE_EMA: deviations from     21, ddof 0
                         EMA centre
  avg_std                mean(std_close, std_open)             —

  Output length = bars held (≤ capacity 2000). With a full 2000-bar seed,
  error vs full-history MQ4 at shift 1 ≈ 0.004 pip (ima240), ≈ 0.7 pip (ima500).
  IndData mfi / obv / rsi exist but are **not** computed (G4).

3. GAPS & DESIGN RISKS (code vs intent / references)
================================================================================

  G1  micro_wave_sig is a proxy; MQ4 microWaveSIG(slope30, slope60, atr*0.10)
      uses expansionCompressionRatio — Strategy_1 is not full parity.
  G2  compute_stencil_kinematics exists but no strategy consumes it.
  G3  MarketMetrics / FEATURE_VECTOR / hold scores not ported (IndData has
      placeholder fields: hold_score, bayesian_hold_score, fractal_alignment, …).
  G4  RSI / MFI / OBV fields unused; PhyBot InitIndData fills them.
  G5  Hardcoded fxpair_arr, volume, period, strategy, thresholds, label in
      code — not config-driven (only dry-run is: --dry-run / CTRADER_DRY_RUN).
  G6  No automated tests (pure functions + dry_run only).
  G7  No reconnect / re-subscribe on disconnect mid-session; refresh token
      never used automatically.
  G8  Opposite signal closes only; next-bar re-entry depends on strategy still
      emitting the opposite side (by design of T2). For Strategy_6 the sticky
      open_sig keeps emitting it, so re-entry happens on the next bar.
  G9  pip_value is approximate (no deposit-currency conversion from Open API).
  G10 [RESOLVED 2026-10-12, V1-T02] Docs drift between AGENTS.md,
      ctraderapp_flow.txt, repo CLAUDE.md and code (strategy 6, label
      cSanOpenAPI, 2000-bar seed). Keep in sync per section 8.
  G11 Logging is print-based; no structured logger or levels.
  G12 ctraderapp.py is large (~830 lines); PnL + lifecycle + bar paths co-located.
  G13 Multi-symbol bar closes can interleave strategy logs; CStrategies.last_t_sig
      is shared across symbols (read immediately after evaluate, so safe today).
  G14 Volume not validated against SymbolMeta min_volume / step_volume.
  G15 No offline backtest harness (hist seed only runs execute=False once).
  G16 Seed window: get_trendbars sizes fromTimestamp as count×1.5×period, so
      across a weekend/holiday fewer than 2000 bars arrive and ima500 is less
      converged (or NaN when < 500 bars).
  G17 cindicators finalize(size=None) silently caps at 500 bars — always pass
      explicit size internally.
  G18 env_setup.txt in the app folder contains plaintext credentials (client
      secret, access/refresh tokens, account id). It must not be shared or
      committed; move secrets to .env only and rotate if exposed.
  G19 [RESOLVED 2026-10-12, V1-T02] ctraderapp_flow.txt now covers strategy 6,
      dry-run CLI, is_spot_event gate, symbol meta, PnL path, 2000-bar seed.
  G20 Strategy_6 runs once per closed bar; MQ4 re-evaluates every tick, so
      intra-bar closes (e.g. PnL ≥ 2.0 reached mid-bar) fire one bar later.
  G21 Label change GrokApp → cSanOpenAPI: positions opened by earlier builds
      under GrokApp are invisible to reconcile/PnL and will not be closed.
  G22 Seed cycle (execute=False) still advances Strategy_6 sticky state from
      the last history bar — intended (mirrors MQ4 warm state) but means the
      first live bar may act on a sticky open_sig computed during seed.

A. Profit average semantics (T7)
   multi-asset: mean over all open labeled positions (sum/count), not per-symbol
   unless get_symbol_trade_profits / all_symbols=False.

B. Period field (T9)
   IndData.period / current_period store **seconds** (M1 → 60), not MQL period
   enum. period_seconds("M1") helper is canonical.

C. PnL ownership (T10)
   Network: CTraderApp (or future PositionPnLService).
   Math: SanUtils only. Never put reconcile inside utils.py.

D. Deferred race (T11)
   Prefer sequential reconcile → unrealized PnL with unique clientMsgId and
   single-flight master Deferred. Joiner Deferreds must not chain strategy
   transforms onto the master (see _share_pnl_result).

E. Migration filter
   Port from HSIG::initSIG / SanSignals / CStrategies live composites only.
   Ignore dead commented strategy blocks and unused San* helpers unless a
   V1 task names them.

F. SDK message delivery (ctrader-open-api 0.9.2)
   Client._received calls the message callback BEFORE firing the request's
   Deferred, for every inbound message (RPC responses included). Any new
   handler on on_message must keep the is_spot_event / executionType gates,
   or history responses will be treated as live bars.
