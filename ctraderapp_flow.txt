CTraderApp lifecycle flowchart
==============================
Source: capp/ctraderapp.py  (+ CTraderOpenAPI in csys/ctrader_api/client.py,
        OrderExecutor in csys/ctrader_api/execution.py)
Entry:  main.py [--dry-run] → CTraderApp(config, active_strategy=8, dry_run=…).run()
Synced with code: 2026-10-12 (V1-T02). Blueprint: design_v1.txt §1.5–1.6.


0. Construction (__init__)
--------------------------
  main.py
    │
    ├─ argparse --dry-run
    ├─ load_config()                         [csys]  (also loads .env into env)
    ├─ dry_run = --dry-run or CTRADER_DRY_RUN in {1,true,yes,on}
    └─ CTraderApp(config, active_strategy=8, dry_run=dry_run)
         │   defaults: trade_volume=10000, trade_label="cSanOpenAPI",
         │             trading_enabled=True
         │
         ├─ self.api = CTraderOpenAPI(config)
         ├─ self.api.on_ready   = self.on_init      # callback when account auth succeeds
         ├─ self.api.on_message = self.on_message   # every extracted protobuf after auth
         ├─ hist_bars, symbol_map, symbol_meta, symbol_digits, current_bar, …
         ├─ bar_period="M1", bar_count=DEFAULT_HISTORY_BARS (2000),
         │  fxpair_arr=[1, 4]
         ├─ self.signals    = SanSignals(default_shift=1)
         ├─ self.strategies = CStrategies(signals, active=6)
         ├─ _pnl_fetch_inflight = None, _pnl_req_seq = 0   # single-flight PnL
         ├─ self.executor   = OrderExecutor(api, volume, label, dry_run, enabled)
         └─ self.utils      = SanUtils(default_label=trade_label)

  No network I/O yet — only wires callbacks and collaborators.


1. run() — fire up
------------------
  CTraderApp.run()
       │
       └─► CTraderOpenAPI.run()
              │
              ├─ connect()  → Client.startService()   # TCP/TLS to demo|live host :5035
              └─ reactor.run()                        # BLOCKS (Twisted event loop)


2. Auth chain (inside CTraderOpenAPI._on_message — before any CTraderApp method)
--------------------------------------------------------------------------------
  TCP connected
       │
       ▼
  _on_connected()
       │
       ▼
  _build_session()                # V1-T42: one Deferred chain per TCP connect
  _authenticate_application()     # ProtoOAApplicationAuthReq
       │
       ▼  (ProtoOAApplicationAuthRes)
  [token expiry known and < 1 day → refresh_access_token()  (ProtoOARefreshTokenReq)]
  _authenticate_account()         # ProtoOAAccountAuthReq
       │   CH_ACCESS_TOKEN_INVALID / OA_AUTH_TOKEN_EXPIRED → refresh → retry once
       ▼  (ProtoOAAccountAuthRes)  → _ready = True
  on_ready()  ──►  CTraderApp.on_init()     # on EVERY connect, not only startup

  Session build failure: before the first ready session → fatal (exit 1);
  later → abort socket, ClientService reconnects (backoff 1→30 s); fatal
  after MAX_AUTH_FAILURES in a row. ProtoOAErrorRes is logged by _emit_error
  and, for api.send() callers, raised as ApiError. send() before ready →
  NotReadyError. Heartbeats are swallowed. Everything else → on_message.

  Health loops (started in connect()):
    heartbeat 10 s   → ProtoHeartbeatEvent
    watchdog   5 s   → silence > 20 s: ProtoOAVersionReq probe; > 40 s or a
                       wall-clock jump (host sleep): abort socket → reconnect
    token     1 h    → refresh ahead of a known expiry
  Disconnect → client logs it (on_status → trade log) → CTraderApp._on_disconnected
  pauses trading (_hist_ready = False) until the rebuilt session reconciles.


3. Startup sequence (after auth) — deferred callback chain
----------------------------------------------------------

  on_init()
       │
       ├─ api.subscribe_spots(fxpair_arr, subscribe_to_timestamp=True)
       │     ├─ ok  → on_spots_subscribed
       │     └─ err → on_subscription_error          # logs; chain stops
       │
  on_spots_subscribed(_)
       │
       ├─ api.get_symbols()                        # ProtoOASymbolsListReq
       │     ├─ ok  → on_symbols_received
       │     └─ err → on_symbols_error              # logs; chain stops
       │
  on_symbols_received(response)
       │
       ├─ fill symbol_map[symbolId] = symbolName
       └─ api.get_symbols_by_id(fxpair_arr)        # ProtoOASymbolByIdReq
             ├─ ok  → on_symbol_details_received
             │          symbol_meta[id] = symbol_meta_from_proto(sym)
             │          (missing id → FX5 defaults digits=5 pip=0.0001)
             └─ err → on_symbol_details_error       # FX5 defaults for all
             both → init_ind_data()
              │
              │  period_secs = period_seconds("M1") = 60
              │  for each symbol_id in fxpair_arr:
              │     hist_bars[id] = IndData(capacity=2000)
              │     apply_symbol_meta(...)  (pip_size, point, digits, period, …)
              │     data.shift = 1
              │     api.get_trendbars(id, "M1", count=2000)
              │        ├─ ok  → on_historical_bars_received(resp, id)
              │        └─ err → on_historical_error(fail, id)
              │
  on_historical_bars_received(response, symbol_id)
       │
       ├─ decode_trendbar(bar, digits) each bar, sort by utc_minutes
       ├─ load_bars() into IndData; remember last utc_minutes
       ├─ run_signal_cycle(data, id, execute=False)   # seed only: NO PnL, NO orders
       │     (see §5; Strategy_6 sticky state IS advanced; Strategy_7 / Strategy_8 stateless)
       ├─ _hist_pending -= 1
       └─ when _hist_pending == 0 → _on_all_historical_loaded()
              │
              │  (on_historical_error also decrements pending → same gate)
              │
  _on_all_historical_loaded()
       │
       ├─ _hist_ready = True
       ├─ executor.sync_positions()                # ProtoOAReconcileReq
       │     (dry_run → succeeds immediately with the local, empty book)
       │     ├─ ok  → _on_positions_synced          # mirror side onto IndData
       │     └─ err → _on_positions_sync_error      # still continues
       │
  _on_positions_synced / _on_positions_sync_error
       │
       └─ _subscribe_live_trendbars()
              │
              │  for each symbol:
              │     api.subscribe_live_trendbars(id, "M1")
              │
              ▼
         *** LIVE LOOP ***  (messages arrive via on_message)

4. Live message loop
--------------------

  NOTE: ctrader-open-api 0.9.2 calls the message callback for EVERY inbound
  message — RPC responses included (GetTrendbarsRes, ReconcileRes, …) —
  BEFORE it fires the request's Deferred. Hence the spot-event gate below.

  on_message(message)
       │
       ├─ if has executionType:
       │      executor.on_execution_event(message)   # fill/close bookkeeping
       │      return
       │
       └─ on_tick(message)
              │
              ├─ return unless is_spot_event(message)   # ProtoOASpotEvent only
              ├─ symbol_id = int(message.symbolId)
              ├─ return if symbol_id not in hist_bars
              │
              ├─ if message.trendbar (live bar payload):
              │      for bar in trendbar:
              │         _apply_live_trendbar(symbol_id, bar)
              │      return
              │
              └─ else (spot bid/ask fallback):
                     mid = (bid+ask)/2  [relative_to_price]
                     ts  = message.timestamp/1000 or time.time()
                     update_current_bar(symbol_id, price, 0, ts)
                     check_for_new_bar(ts)
                          │
                          └─ if bar_interval boundary crossed:
                                 on_bar()   # synthetic bar path


4a. Official live trendbar path — _apply_live_trendbar
------------------------------------------------------

  _apply_live_trendbar(symbol_id, bar)
       │
       ├─ decode_trendbar(bar)
       │
       ├─ first bar for symbol (prev is None):
       │      update_last_bar (same time) OR append_decoded_bar
       │      store _last_live_bar_minutes[id]
       │      return
       │
       ├─ same minute as prev:
       │      update_last_bar(...)   # forming bar OHLCV only
       │      return                 # NO signal cycle
       │
       └─ new minute (minutes > prev):
              data.new_bar = True; prev/new bar open times
              append_decoded_bar(...)
              run_signal_cycle(data, symbol_id, execute=True, log_bar=True)
                  (async: returns a Deferred; logging happens on finish)
              _fire_on_bar_event()                # optional handlers


4b. Synthetic bar path (no live trendbar on spot)
-------------------------------------------------

  update_current_bar → check_for_new_bar
       │
       └─ on_bar()   # for each symbol in current_bar
              ├─ hist_bars[id].append_bar(...)
              ├─ run_signal_cycle(data, symbol_id, execute=True,
              │                   log_bar=True, log_tag="synthetic")
              ├─ reset current_bar to next open
              └─ _fire_on_bar_event()


5. Once-per-cycle decision pipeline — run_signal_cycle
------------------------------------------------------

  run_signal_cycle(data, symbol_id, execute=True|False, log_bar, log_tag)
       │
       ├─ refresh_indicators(data)
       │      └─ compute_indicators(data)
       │           ima5..ima500 SMMA; atr(21, mean TR); adx/di±(21, Wilder);
       │           std_close/std_open(21, EMA centre); avg_std
       │
       ├─ if not (execute and _hist_ready):          # seed path, synchronous
       │      _finish_signal_cycle(total_trade_profits=0, execute=False)
       │      return SIG
       │
       └─ live path, asynchronous:
              fetch_position_pnls()                  # single-flight
                 │  dry_run → succeed([])
                 │  in-flight exists → _share_pnl_result(master)  (join)
                 │  else master = _start_pnl_fetch():
                 │       api.reconcile(pnl_reconcile_<seq>, timeout=30)
                 │       → executor.sync_from_reconcile(rec)
                 │       → api.get_unrealized_pnl(pnl_unrealized_<seq>, timeout=30)
                 │       → _build_position_pnls(rec, pnl)  → list[PositionPnL]
                 │       (reconcile error → []; PnL error → net_profit 0)
                 │
                 ├─ ok  → _on_position_pnls_ready
                 │          avg = SanUtils.get_total_trade_profits(pnls, label)
                 │          _finish_signal_cycle(avg, execute=True)
                 └─ err → _on_position_pnls_error
                            _finish_signal_cycle(0.0, execute=True)

  _finish_signal_cycle(data, sid, total_trade_profits, execute, log_bar, log_tag)
       │
       ├─ strategies.evaluate(data, total_trade_profits, strategy=active)
       │      ├─ signals.init_sig(data) → T_SIG
       │      │     slopes slope_val(ima240|ima30, 5, 21, shift=1)
       │      │     base_slope_sig / slope30_sig (+ _v1: ATR-relative acc, flat-regime hysteresis per symbol), fsig*, fast_sig, micro_wave proxy
       │      └─ Strategy_N(t_sig[, pnl][, symbol_id]) → SIG
       │            Strategy_8 (live): peak_trough_sig swing (V1-T44: ATR zigzag regime, per-symbol state), BUY/SELL → side, CLOSE → CLOSE
       │            Strategy_7: base_slope_sig_v1, flat→CLOSE, decel CLOSE if pnl>=2
       │            Strategy_6: MQ4 baseSlope composite, sticky per-symbol state
       │
       ├─ store last_t_sig[sid], last_trade_sig[sid], last_total_trade_profits
       │
       ├─ _sync_position_state(data, sid, trade_sig)
       │
       ├─ if execute and _hist_ready:
       │      executor.handle_signal(sid, trade_sig)
       │         │
       │         ├─ disabled / pending   → skipped
       │         ├─ flat + BUY/SELL      → open market (no SL/TP), label cSanOpenAPI
       │         ├─ same side / neutral  → no-op
       │         ├─ opposite / CLOSE     → close position (no reverse)
       │         └─ (network: new_market_order / close_position;
       │             dry_run: simulated fill/close)
       │      _sync_position_state(...) again
       │
       ├─ if log_bar: _log_cycle_result → "New bar closed [SYM] … avgPnL=… SIG=…"
       │
       └─ return trade_sig


ASCII (signal cycle):

  run_signal_cycle
    │
    ├─► refresh_indicators ──► compute_indicators
    │
    ├─► [live] fetch_position_pnls ──► SanUtils.get_total_trade_profits
    │
    └─► _finish_signal_cycle
           ├─► strategies.evaluate
           │      ├─► SanSignals.init_sig  (fsig*, baseSlope, slope30, fastSIG, …)
           │      └─► Strategy_1..6 → SIG   (live default: 6)
           ├─► _sync_position_state
           ├─► [if live] executor.handle_signal ──► _sync_position_state
           └─► [if log_bar] _log_cycle_result

8. Flags that gate behavior
---------------------------

  _hist_ready
    False until all historical trendbar requests finish (ok or error).
    PnL fetch and orders happen only when execute=True AND _hist_ready.

  execute= (arg on run_signal_cycle)
    False on historical seed (indicators + signals, no PnL, no orders).
    True on live bar close (default).

  executor.dry_run   (main.py --dry-run / CTRADER_DRY_RUN)
    Simulated fills/closes; PnL fetch returns []; startup reconcile skipped.

  executor.enabled
    Master switch; False → handle_signal returns "skipped".

  _pnl_fetch_inflight
    Non-None while a reconcile → unrealized PnL chain runs; concurrent
    symbol cycles join it instead of starting another.
